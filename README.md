# Paras Rahul Pingale — Portfolio

An interactive React landing page with a Spring Boot API starter.

## Run the frontend

```bash
npm install
npm run dev
```

## Run the Java API

```bash
cd backend
mvn spring-boot:run
```

The API is available at `http://localhost:8080/api/profile`.
